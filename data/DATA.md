# Certificate data

## Range through `10^8`

The archived certificate stream through `10^8` contains 5,757,686 certificates:

- 5,756,322 primes in `(5×10^4, 10^8]`;
- 1,364 prime powers `p^m <= 10^8`, `m >= 2`.

Breakdown:

- 652,959 `C4`;
- 5,096,876 `C4F`;
- 7,851 `DS`;
- no unresolved field.

All `DS` cases occur at `q <= 3,098,633`.

## Range `(10^8, 2.6×10^10]`

The completed production run contains:

- 1,127,956,365 primes;
- 13,992 proper prime powers;
- 1,127,970,357 fields total.

Every field is certified by `C4F`:

- `C4F = 1,127,970,357`;
- `C4 = 0`;
- `DS = 0`;
- `UNRESOLVED = 0`;
- `failures.csv` is empty.

The raw run has exactly 1559 files:

- `pp.csv.gz`, `pp.stats`, `pp.done`;
- `summary.txt`, `failures.csv`.

A full integrity pass verified all 519 gzip streams and produced SHA-256 manifests; the final status was:

```text
OVERALL: PASS
```

## Certificate columns

```text
q, type, p, m, method, detail
```

| column | meaning |
|---|---|
| `q` | field size `p^m` |
| `type` | `p` for prime fields, `pp` for `m >= 2` |
| `p` | characteristic |
| `m` | extension degree |
| `method` | `C4`, `C4F`, or `DS` |
| `detail` | sieve parameter or explicit witness data |

## Reproducibility

The complementary range is generated by:

```bash
cd code
python3 run_all.py --lo 100000000 --hi 26000000000 --procs 8 --outdir results
```

All pseudo-random choices are seeded deterministically by `q`, so individual fields can be re-certified independently.
